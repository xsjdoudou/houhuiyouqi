# 后会友期人格测试

微信小程序：16 道题，每题 4 个选项，匹配一位可能成为好朋友的嘉宾并展示理由，支持云端记录、删除记录和分享结果。嘉宾画像和匹配是主观趣味设定，非官方测评，不代表嘉宾真实性格、实际交友意愿或心理诊断。

## 导入和部署

1. 在微信开发者工具选择「导入项目」，项目目录选择本文件夹，填入自己的小程序 AppID。不要直接使用示例的 `touristappid`。
2. 点击「云开发」，按提示开通并选择默认云环境。留意开通页面显示的费用和额度。如果有多个环境，在 `miniprogram/app.js` 的 `wx.cloud.init` 中指定 `env: '你的环境ID'`。
3. 在云开发控制台的数据库中新建集合 `test_records`，设置为仅云函数可读写（禁止小程序客户端直接读写）。记录通过云函数按微信身份隔离。
4. 在项目文件树中右键 `cloudfunctions/records`，选择「上传并部署：云端安装依赖」。如果云函数目录未关联环境，先在开发者工具中选择对应云环境。
5. 点击编译。完成测试后应显示「已保存到我的记录」；从首页进入「我的测试记录」确认读取与删除。用真机预览确认分享。

分享链接只包含结果类型和版本，不包含用户身份、原始答案或记录 ID。当前不保存原始答案，历史列表最多显示最近 100 条。若保存失败，结果页会明确提示。修改嘉宾画像及计分后必须重新上传并部署 records 云函数，旧版记录和分享链接保留原版本的结果文案。

上线前请根据实际数据处理方式配置隐私保护指引，核对类目、审核、云服务费用及节目和嘉宾相关的名称、肖像等使用授权。题目和结果文案是原创示例；修改题数或计分规则时，需要将 `miniprogram/utils/content.js` 同步到 `cloudfunctions/records/content.js` 并重新部署云函数。
